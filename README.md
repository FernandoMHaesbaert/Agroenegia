## 🎯 Visão Geral do Projeto

Este projeto tem como objetivo **[Descreva aqui o propósito do seu projeto - Ex: "compartilhar análises, relatórios e visualizações de dados sobre a eficiência energética ou uso de insumos na agricultura"].**

O conteúdo principal do site é gerado a partir de arquivos `.Rmd` (R Markdown) ou outros documentos, compilados em **HTML** para visualização online.

## 🛠️ Tecnologias e Ferramentas

* **R Markdown (`.Rmd`):** Linguagem principal para geração de relatórios e análises.
* **HTML/CSS/JavaScript:** Conteúdo web final renderizado.
* **Pandoc:** Utilizado para a conversão de formatos de arquivo.
* **GitHub Pages:** Serviço de hospedagem usado para publicar o site.
